# برنامج إنشاء ملفات مراقبة الامتحان التكميلي 2026 — نسخة 32-bit

مجلد العمل: `exam_monitoring_32bit/`

## ما تم إصلاحه فورًا
آخر رسالة في سجل المحادثة (chat-export) تُظهر فشل تشغيل
`create_all_previous_requests_file.py` بالخطأ:

```
SyntaxError: unterminated triple-quoted string literal (detected at line 149)
```

السبب: المحتوى كان داخل `CONTENT = r'''...'''` وكان النص نفسه يحتوي على تسلسل
`'''` فأنهى السلسلة الثلاثية مبكرًا.

الحل: إعادة كتابة السكربت بحيث يُخزَّن المحتوى كقائمة أسطر عادية بدون أي سلاسل
ثلاثية داخل النص، مع فحص ذاتي قبل الكتابة. **تم التحقق**: الملف يُترجم ويعمل بنجاح.

```bash
python create_all_previous_requests_file.py
# Created: ALL_PREVIOUS_REQUESTS.md
# ZIP created + SHA-256 + ملف .sha256
```

## أهم القرارات المتفق عليها (تفاصيلها في ALL_PREVIOUS_REQUESTS.md)
1. دخول برقم وزاري أو وطني فقط، خروج بعد 3 محاولات خاطئة.
2. اختيار المدرسة (برقمها الوطني أو بحث بالاسم/التشابه) إجباري قبل فتح النماذج،
   واسم المدرسة يُعبّأ مرة واحدة.
3. بيانات الموظف تظهر تلقائيًا من Excel بمجرد إدخال رقمه؛ إدخال يدوي فقط عند عدم العثور.
4. التخصص: من PDF بالاسم الصريح (عربي = اللغة العربية = عربية...)، وإلا من Excel
   كما هو حرفيًا مع تسجيل المصدر، وإذا كان فارغًا في Excel تُعتمد "أخرى".
5. الهاتف: 10 خانات تبدأ إلزاميًا بـ 077/078/079/076.
6. حفظ DBF كما الأصل + Excel محمي للراغبين (الإلكتروني)، قفل البيانات بعد الإدخال،
   طباعة وتصدير في كل نافذة، نوافذ عمودية متلاءمة مع كل الشاشات، رسائل احترافية،
   قسم مساعدة وتواصل واتساب، والشعار الجديد في رأس كل النماذج.
